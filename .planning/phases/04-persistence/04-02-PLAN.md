Unit tests (no LLM — use in-memory SQLite conn passed explicitly):

    test_save_and_load_roundtrip:
      - Build minimal DebateReport with known field values
      - save_debate(report, conn)
      - loaded = load_debate(report.debate_id, conn)
      - assert loaded is not None
      - assert loaded.debate_id == report.debate_id
      - assert loaded.topic == report.topic
      - assert loaded.confidence_score == report.confidence_score
      - assert loaded.convergence_status == report.convergence_status
      - assert loaded.consensus_points == report.consensus_points

    test_load_nonexistent_returns_none:
      - load_debate("no-such-id", conn) is None

    test_upsert_replaces_existing_row:
      - save_debate(report, conn) twice with same debate_id, second with modified topic
      - load_debate returns the second version's topic (INSERT OR REPLACE)
      - list_debates(conn) returns exactly 1 row

    test_list_debates_structure:
      - save 2 reports with different debate_ids and topics
      - rows = list_debates(conn)
      - assert len(rows) == 2
      - assert all("report_json" not in r for r in rows)
      - assert all({"debate_id","topic","created_at","status"}.issubset(r.keys()) for r in rows)

    test_list_debates_empty_db:
      - list_debates(conn) == []

Integration tests (require LLM — mark @pytest.mark.integration):

    test_full_graph_saves_to_db:
      - Run graph.invoke({"topic": "Is remote work beneficial?", "max_rounds": 1}, ...)
      - Pass a real temp-file DB path via get_connection(tmp_path)
      - BUT: save_node uses the module-level singleton; to intercept, monkey-patch
        debate.nodes.save.save_debate to call save_debate with an explicit conn
        OR simply query the default debates.db after the run.
      - Simpler approach: after graph.invoke, open debates.db (created at project root),
        query for the debate_id from final_report.debate_id, assert row exists.
      - Assert row["topic"] == "Is remote work beneficial?"
      - Assert row["status"] in ("converged", "max_rounds", "partial")

    test_replay_by_debate_id:
      - Run graph.invoke (max_rounds=1) to produce final_report
      - debate_id = final_report.debate_id
      - Load from default DB: loaded = load_debate(debate_id)
      - assert loaded is not None
      - assert loaded.debate_id == debate_id
      - assert loaded.topic == final_report.topic
      - assert loaded.confidence_score == final_report.confidence_score
      - assert loaded.convergence_status == final_report.convergence_status
      - assert len(loaded.reasoning_trace) == len(final_report.reasoning_trace)

   ```python
   import sqlite3 as _sqlite3
   from debate.store import DB_PATH
   verify_conn = _sqlite3.connect(str(DB_PATH))
   verify_conn.row_factory = _sqlite3.Row

   ).fetchone()
   verify_conn.close()
   assert row is not None
   ```
